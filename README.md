# AWS + Terraform Labs

Практичні роботи з курсу "AWS + Terraform". Репозиторій містить конфігурації для розгортання хмарної інфраструктури.

## Структура проекту
* **lab01-iam** — Налаштування користувачів та прав доступу.
* **lab6 - lab9** — Робота з мережами, VPC та інстансами EC2.
* **lab10 - lab11** — Просунуті налаштування інфраструктури та моніторинг CloudWatch.

## Інструменти
* **Terraform** — Infrastructure as Code.
* **AWS** — Cloud Provider.
